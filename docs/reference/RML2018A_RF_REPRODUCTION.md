## 1. 当前可复现的接线与参数

链路为 **AGX USB3 → B210 RF A TX/RX → 20dB衰减器＋15cm SMA同轴 → P201 RX1 → 网口 → AGX处理**。
用户早期称N210的设备实际枚举为B210，serial2508504；当前不经NX发射。
B210与P201的程序目录分开，共享一份原HDF5，详见[设备工作区](../../devices/README.md)。

| 项目 | 本次有限先导实际设置/身份 | 复现时的含义 |
| --- | --- | --- |
| B210 | serial2508504，AGX USB3，通道0、subdev A:A、UHD天线TX/RX | 外部有限信号源；UHD内部端口命名与面板名分别保存 |
| P201 | 192.168.1.10:43110；RX1/RX0/A_BALANCED；手动增益 | 唯一生产受控SDR，保持RX-only |

## 2. 接收处理及优化状态

| 环节 | 当前实验行为 | 对未来空口接收的适用条件 |
| --- | --- | --- |
| 数字峰值与TX增益配对 | 提高数字幅度、降低硬件TX增益；曾实测降低LO相对影响 | 可作为发射机校准思路；更换设备/功率/波形后重新测量，不能照搬增益数值 |
| 导频同步/CFO/公共相位 | 129抽头Hamming、500kHz低通仅作检测；搜索±14.5kHz，500Hz步进，最终绝对限17kHz；初始/最终门0.55/0.65 | 当前需要已知导频；未知发射机必须另有盲同步或可识别协议结构 |
| 保护区LO校正 | 原训练半窗估计一个固定复数单音；`guard-tone-block-margin-v1`检查全部训练/留出半段 | 需要已知静默区及捕获期间稳定LO；多径尾迹、突发和频漂可能破坏假设 |
| 相消门 | 每半段192点、8个24点块，误差余量≤sqrt(0.1)，稳定性与导频检查；原v1结果同时保留 | 不按真实类别调门；校正拒绝时原始IQ及原因保留，不强行输出“干净”数据 |
| RX40→RX50 | QAM匹配实测有收益；剩余16类采用RX50 | 是本接法的增益/ADC余量选择；空口强邻道可能使同档增益削顶 |
| 导频时序校正 | 已做有限对照；没有纳入剩余16类的识别处理 | 更正时序通常值得研究，但本实验总识别收益不一致，不能默认对所有类有利 |
| 固定500kHz载荷滤波 | 只作对照，当前未默认启用 | 必须保留调制特征；同频干扰与目标频谱重叠时，普通滤波不能无损分离 |
| 归一化/分类 | 每个1024点载荷做复数RMS归一，float32 [2,1024]，24类logits/argmax | 数据接入规范与训练域必须一致；仅提高SINR不保证提高识别率 |
| SINR记录 | 原Z为source_snr_db，源辅助交叉拟合得到条件有效rx_sinr_db | 本实验依赖源X/Z；未知实收没有这两个真值，不能直接沿用为物理SINR实测 |

## 4. 同轴、空口与论文证据

对于最终面向无线信号的模型，推荐论文采用三层证据：

| 实验层 | 主要回答的问题 | 尚不能支持的结论 |
| --- | --- | --- |
| 离线原IQ | 数据集任务上的算法性能与计算开销 | 真实RF前端或空间传播适应性 |
| 衰减同轴硬件回放 | 经过真实DAC/混频/ADC/传输后性能如何；校正的配对消融 | 多径、路径损耗、移动、真实共信道干扰下的泛化 |
| 空口天线实验 | 在规定距离/场景/时间/干扰条件下能否识别 | 没覆盖的新设备/新场景或所有未知协议都可泛化 |

同轴适合建立可控硬件基线、调通系统和定位损伤；它仍有器件噪声、LO/CFO、非线性和阻抗误差，
不能称理想无噪声信道，也不能把20dB衰减器写成20dB SNR。
空口增加传播衰减、多径与时变因素，对真实部署的证明力更直接，但也更难归因和复现。
论文若主要研究识别算法，同轴可作为硬件补充；若宣称实际无线部署，建议空口结果作为关键验证，
同轴作为解释性能差异的基线。最终接收未知无线电发射时使用天线；同轴主要是实验连接。

目前已知帧结构辅助的优化可以迁移为协作式链路的工程方案：发射端控制数字幅度和发射链路线性余量，
接收端进行增益管理、同步/频偏补偿及满足假设的LO校正。但未知发射机不能要求它发送我们的导频/保护区；
广义盲AMC还需要检测、频段分离、采样率/符号率适配和不依赖已知payload的同步等前端。
未知条件下质量可记录功率、削顶、检测/同步结果或经独立验证的盲估计，不能假装拥有源X/Z来算当前SINR。

将真实SDR/AGX实验写入论文通常能增强工程可信度，价值来自可复现对照、合理证据边界和新场景结果，
不由“用了SDR”本身保证创新性、录用或加分。功率设置、同步和常规校正常作为必要实验方法；
若将某项校正主张为算法贡献，还需相关工作比较、清晰假设、复杂度与独立数据消融，不能仅凭本批改善断言新颖。
比较不同识别模型时，应共享相同前端、源成员与实收输入、划分和计算预算，把网络收益与同步/校正收益分开。

建议论文记录以下可比较指标与分组；这是研究建议，本次不启动实验或训练：

1. 各类准确率、macro-F1、混淆矩阵；同时给出源模型对照，区分源模型误判和新增链路损失。
2. 分开报告检测/同步成功率、同步成功条件下分类准确率，以及全部预登记发射样本为分母的端到端正确率；
   未同步、估计无效、校正拒绝、削顶和超时均保留。因提前中止未执行的计划样本另列，不能伪装成已测。
3. 源Z、各接收处理面的条件SINR及无效计数分别画图。未知空口不直接沿用依赖源的SINR分箱。
4. 固定硬件/输入的原始、LO校正和待验证滤波/时序消融；不依据真实调制类别选择最有利处理。
5. 固定测试规则后，在不同采集session/日期/位置、距离、视距/非视距与干扰条件下复测，记录天线型号、
   极化、高度、方向、功率/增益、带宽和环境。需要功率/SINR定量结论时补实际校准。
6. 数据按源样本及其全部重发/派生后代、session/day隔离；调参数据不能回流到最终独立测试。
   相邻窗口和重复帧不是独立样本，置信区间应尊重采集组相关性；每类24条不足以支撑广泛稳健性结论。
7. 若主张边缘部署，报告实测采集到结果时延、吞吐、内存、持续运行和失败恢复；模型单独推理速度不能当端到端实时性能。

原RML2018A样本已含噪声/信道损伤，同轴或空口重放会叠加新损伤。
因此可以保留它作为“带既有损伤的RF回放”工程基准；若研究可控物理SNR或干净发射泛化，
可另建经独立调制/星座/EVM检查的干净生成源与可控噪声/信道实验，不必立即替换原数据集。
原Z和新增损伤不能直接按dB相减，也不能把发送Z=0dB等同接收物理SINR=0dB。
当前全库源访问包含历史训练成员，现有结果不能标成未见样本的独立泛化准确率。

> 本文建立B210–P201–Jetson AGX的衰减同轴RF回放平台，使用已知导频和保护区完成同步及条件性LO校正。

## 5. AM单边带的条件SINR与识别报告（2026-09-13补充）

[离线复核](../validation/RML2018A_FULL_RF_CAMPAIGN_2026-09-10.md#2026-09-13am单边带指标适用性离线复核)
复用既有两类SSB、DSB-WC及BPSK的96行，不改2026-09-12快照、原始记录或生产估计器。
SSB-WC/SSB-SC这两批1024点源窗的均值功率占比中位99.67%/99.10%；
该量是有限窗常量投影，包含低频缓变分量，不能直接命名为独立测得的载波功率，尤其不能据此更改SC/WC标签。

当前方法在每个512点训练半窗去均值后拟合复增益，再预测另一半的**完整源X**。
令预测X总功率为Q、交叉预测残差功率为E、α=1/(1+10^(Z/10))，记录的条件有效SINR为：

```text
10 log10[ (1−α) Q / (α Q + E) ]
```

Z只是数据集给定的名义SNR；此式假设名义功率分配和单一复增益适用，不分离干净调制信号、载波、源噪声和硬件失真。
SSB源窗可供拟合的中心化变化量很小，小的新增误差就可能使两半增益估计不一致，预测完整X时又影响占比很高的常量分量。
一条SSB-WC参考即使理想回放y=X也不能通过可辨识门；其余95条理想对照有效，不能将所有实收无效都归于源窗本身。
本次不放宽门限、不将去均值后的残差另称“物理SINR”，也不改变模型输入预处理。

论文及统一24类工程结果建议逐类同时报告：

- 源Z、原始/LO后条件SINR的有效条数/总条数、仅有效子集的中位数及无效原因分布。
- 源/原始/LO三组正确数/完整源行分母，另列同步失败、缺失预测和逐条纠正/回退。
- SINR有效/无效与识别正确/错误的交叉计数；不可仅保留SINR有效行来计算总体识别率。

本次SSB-WC/SSB-SC的LO后有效SINR分别14/24、8/24，无效26条中21条识别正确。
`invalid`保留null及原因，不填0、不当成未接收，也不解释为真实SINR必然低。
两类源与LO后预测47/48一致，LO后的11条误判均在源输入上也误判；这提示源域短窗类别混淆需要单列。
原始实收WC24/24、LO16/24的下降仍如实保留，不能凭预测一致性证明LO处理完全无损或将这批原始识别增益当可靠泛化收益。

可用于论文的方法表述：

> 本实验保留原始数据集的名义源SNR，并报告已知源参考辅助的条件有效接收SINR。
> 该指标包含新增链路失真，依赖有限窗内的增益可辨识性及稳定性，不作为校准物理SINR或仅调制分量SINR。
> 对未通过估计检查的样本保留无效原因，识别结果仍计入完整分母；同步、质量有效率和识别正确率分别统计。
