## 已知情况与尚未归因

相近调制混淆、环境噪声/多径、频差、采样时钟差，以及设备I/Q不平衡、相位噪声、
非线性等可能共同形成域差异。设备指纹是可能的稳定特征，不能把所有剩余扰动都
认定为指纹或正常干扰；过载、异常突发、掉样和预处理错误仍须单独排查。
依据为[多类对照](../validation/B210_MULTICLASS_VALIDATION_2026-09-07.md)与
[逐点剩余误差诊断](../validation/B210_RESIDUAL_VALIDATION_2026-09-07.md)，不外推为独立RF准确率。

## 后续模型工作重新启动时的建议

1. 保留冻结模型作基线，先排除明显链路问题；衰减器到位后可做有界同轴对照，
   不以低发射增益代替衰减器直接连接TX/RX。
2. 在已有语料体系中准备经独立审核的实收标签，覆盖类别、接收强度、时间、
   距离和设备条件；来源用发射记录/哈希/接收关联证明，不用预测或置信度造标签。
3. 优先参考实测范围做受控噪声、频差/相位、多径、采样时钟和适度I/Q失衡增强，
   再考虑真实接收数据微调；不默认从头重训，不让模型学习掩盖故障。
4. 原始行与全部派生/重复窗口保持同一分组，按source/session/day隔离训练与验收；
   同一1024点波形重复接收不能跨集合。归一化和四窗输入组织必须匹配部署语义。
5. 噪声、严重混合或不可辨识输入用于拒识/质量研究，不强迫归为已知类别。
   独立known-RF/OOD覆盖不足时不冻结温度/拒识阈值，不读取locked test。
