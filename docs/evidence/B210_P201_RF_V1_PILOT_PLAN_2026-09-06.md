# B210 → P201 → RF-v1 识别/证据接入联调预登记

用户在本任务明确要求 NX+B210 天线发射、P201 接收、2.4 GHz，并授权沿历史参数
有限重试。本单元是 V1b 前的联调与来源关联验证，不将 TX 加入 P201/Planner，
NX 不承担推理。基线 b99a85f6b83ceb75dffde98112b12bc008200a44。

复用已确认的 B210 serial 2508504、RF A/TX-RX/channel 0，2.440 GHz、2.1 MS/s、
1.5 MHz、gain 70 dB、复数峰值 0.2，单次发送 21000000 样本（名义 10 秒）。
源仅为既有四个 train 行 102400/102401/102403/102404，数字 ID 0、名称 provisional。
不读 locked test，不增加数据集行，不训练、不改变 epoch-10/FP16/RF-v1。
已见过的 train 波形不能充当独立 calibration/acceptance 源，重复周期不是独立样本。

最多一次注册 TX burst。P201 RX1/RX0/A_BALANCED、2.1 MS/s、1.5 MHz、gain 50，
停发前/发射中精查/停发后各 65535 ci16（各262140 bytes），发射中另取一份4096
ci16（16384 bytes）供 RF-v1 和语料接入；总 RX 最大 802804 bytes。前三者中心
2.440 GHz、settle 500 ms；4096窗中心由发射中精查的既有谱估计决定（必须位于
2.440 GHz±750 kHz），settle 100 ms；所有 capture timeout 1000 ms。适用计划先经
原生 Controller 校验，打印 free space（至少 8 MiB）、精确目录与 generation stop。
若任一步失败不扩大功率/时长/样本量，保留失败并停止。

AGX/NX 的本单元目录均为 /var/tmp/sdrharness-dev/b210-pilot-906a/。RX owner 有
15 秒通信上限、原生 restore/stop；直接 stop 为 Controller generation cancel。
TX helper 等显式 GO，注册字节数/有限 feed watchdog，外层 timeout 65 秒；直接
stop 为经 feature 命令行核对的 helper PID 的 SIGTERM。最终确认 TX/UHD 退出、
FIFO 清除、P201 状态与 daemon 不变、所有精确临时路径不存在。

先完成 source-only 证据处理，再打开模型结果。诊断采用冻结 source 的 99% 能量
频带（仅用于对齐，不改 RF-v1 输入），对4096接收窗计算循环包络最佳相关，并将
同一分析施加到两个停发窗的各4096片段。报告相关分布与歧义，不据此自动贴标签；
不拟合或冻结识别拒识阈值。

新增 receive-file 工程入口以此前精查与之后 capture 的独立 sequence、完整计划/
报告、原始 IQ SHA-256、固定 RX 身份及同窗频谱复算校验，复用 build_model_ready_batch
和 S3 Worker；保持原始观测时间，产物标记 received replay，非 synthetic input。
使用既有 S6a 归档和 V1a unknown/receive_domain 导入/派生，演练后人工删除私有
应用记录并清理，不写用户生产库。原始 native report 与移除已删除 SigMF 描述的
语料 report projection 分别保留 hash，采样字段不改写；不制造缺失的 capture。

本轮仅完成联调工具与隔离实机/接入证据。V1b 仍需独立来源、盲审标签、覆盖与
source/session/day 分组；V2/V3b/A1 不前移。因已查看工程模型结果，本单元 session/
day/源只能 receive_domain。结果界面不能把未准入 top-1 称为已确认分类。
