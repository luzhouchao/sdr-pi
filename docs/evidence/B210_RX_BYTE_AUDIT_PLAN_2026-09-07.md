# RX 字节与缓冲边界诊断登记

基线 `1ff065d`。用户已确认没有50Ω负载，输入隔离实测待设备到位。
本单元只读既有2455 MHz ABBA包的15份IQ（包括tone及全部停发对照），
核查软件格式/整块重复/补零/缓冲边界迹象，不重新采集或运行模型。

方法在本次数值分析前固定：

- 先验证原67文件库存的路径、长度、SHA-256，再复用原采集身份校验。
- 每份必须65535个ci16_le样本，独立Python struct解码与NumPy逐值相等；
  核对12-bit有符号扩展及I/Q范围，同时记录字节交换解释下的越界数量。
  这些检查不能排除所有仍合法的字节错误，也不是端到端传输校验和。
- 检查全部样本的连续同值/全零最长串；对128和4096点完整对齐块计算精确
  重复组（含跨采集），尾部127/4095点不冒充完整块。重复只算可疑线索。
- 当前P201只读配置buffer=4096；记录每个4096边界的一阶差分幅度和在全部
  差分中的百分位，以及边界前后各128点功率。对全部128分段的相邻功率
  跳变量排序，报告最大10项及其offset modulo4096。无新通过阈值，不能由
  边界相关性断言DMA错误，也不能由缺乏边界相关性证明无掉样。
- 原源相关门、四窗、分类结果、RF-v1、模型和生产不可用状态保持。

只读核对P201 sysfs采样格式、索引、scan/buffer状态、当前配置和daemon身份；
不写IIO、不启动第二collector、不改部署。记录当前事实与历史证据的区别。
测试涵盖负数端序、错误字节序、重复缓冲、补零、边界突变与非边界突变、
截断及尾部覆盖。测试目录仅用 `/var/tmp/sdrharness-dev/b210-byte-audit-907q/`，
完成后精确清理；不新增或复制原始IQ。
