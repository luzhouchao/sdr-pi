基线 f676e06ad9bf8be77ec8769f53dfeca4e480fab9。用户继续授权既有 NX+B210 天线、
2.4 GHz、P201 接收联调。上轮50 dB停发后削顶失败原样保留；本单元用低10 dB的
**40 dB诊断接收**检查余量，并复用历史单音独立测频差的来源分析。不能据此声称
50 dB RF-v1 对照或识别准确率已通过；RF-v1/profile/epoch-10/FP16 完全不改，本轮
不运行模型，不读新数据集行、locked test，不贴独立标签或冻结生产阈值。

TX gain70、幅度0.2；不增加功率或时长，不失败后继续试参数：

   P201 RX rate2.5 MS/s、BW1 MHz、gain40、中心2.440 GHz。

   rate2.1 MS/s、BW1.5 MHz、21000000样本，名义10秒。RX相同rate/BW、gain40、中心2.440 GHz。

实际启动前LO/rate/BW/gain/scan/buffer，验证daemon不变、generation临时目录消失。
直接停止为Controller generation cancel；tone由精确feature cwd和timeout命令行核对
的远端PID接收SIGINT，RML由核对命令行的helper PID接收SIGTERM，helper负责子进程/
FIFO清理。远端timeout分别35秒/65秒兜底，有限nsamps/FIFO feed独立限制RF时长。
启动receipt以exclusive创建，禁止相同目录重复/并发运行；SIGINT/TERM进入清理。

在取得本轮数据前冻结**工程对照判据**，非模型拒识或生产门：
- 六个捕获均原生成功、无削顶/丢样/溢出/timeout/身份或恢复错误。
- 单音发射中观测bin相对两个停发对照均提高至少20 dB，且高于发射中频谱中值至少20 dB；
  取该独立tone观测偏移减100 kHz作为RML诊断频差，不用模型/新RML拟合CFO。
- 复用source自身99%能量带限、同样校正所有RML接收；仅用于离线诊断，不改原始IQ。
  前7个4096窗最佳lag的中位数固定为lag，原样施加后8窗和两个停发对照。
  RML后8窗固定lag相关中位数≥0.5，两个停发中位数绝对值均≤0.2，
  发射中中位数减最大对照绝对值≥0.3。无判据重试/事后修改。

同一capture内前7/后8窗不是独立样本，train周期和已查看session/day不计V1b。
结果保留原始报告/源/脚本/IQ哈希、有界相关和明确判定，不保留Git IQ。所有feature
进程、两端临时路径与测试目录精确清理后才勾选准确对应的子项；原50 dB失败不抹去。
