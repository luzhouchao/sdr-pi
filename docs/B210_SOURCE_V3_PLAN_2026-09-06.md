## 判据依据与冻结规则

v2将“固定延迟下停发噪声≤0.2”也用于“错源参考搜索4096个延迟后的最大相关”，
两种统计量不等价。搜索会抬高偶然相关；源谱越集中，可独立区分的维度越少。
简单增加固定上限仍不能适应不同源频谱。本轮采用条件于源频谱、搜索流程相同的
有限错源集合，与真正源的保留段分数直接比较。

新增独立 `assess_centered_source_v3` API，复用v2数值路径，v2默认行为不变：

- 保留前7原始窗拟合、后8原始窗验证、独立FFT、一次lag/剩余频差估计。
- 保留源非DC有效bin数≥8；前段相关≥0.2、相位RMSE≤0.2 rad、剩余频差≤200 Hz。
- 保留后段同源中位数≥0.8、每窗≥0.6；两个停发对照所有窗≤0.2，正例中位数
  减停发最大值≥0.6。任何一项失败仍拒绝。
- 错源从3个扩为31个，种子9060701至9060731，保持每个源的FFT幅度和真实DC，
  只随机相位。每个错源都执行相同的完整前段lag/频差估计，并在后段固定验证。
  无额外频差网格或后段搜索；估计失败仍用前段lag、未精调tone频差报告后段分数。
- 用 `min(同源后8窗相关) - max(31个错源×8窗相关) ≥ 0.3` 替代v2错源≤0.2。
  0.3沿用已有工程来源区分差值的量级，在新样例执行前固定；这是明确的工程
  分离裕量，并非从旧两例拟合的误接收率阈值。比较使用最差同源窗与最强错源窗，
  不通过中位数掩盖一个歧义窗。

源谱的有效bin数继续显式报告，错源集合也保留同一谱形，因此自然反映源的谱集中
程度及实际搜索带来的偶然匹配。31个有限随机参考只能提供工程反证，既不穷尽
所有错源，也不保证交换性；**不将排序或零误接收宣称为p值、统计显著性或RF/OOD
false acceptance上界**。纯载波及谱高度集中的信号仍可能不可判定。
