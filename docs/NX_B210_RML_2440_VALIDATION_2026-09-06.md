## 结果与授权边界

用户本次明确指定 NX+B210 发射、P201 接收、使用 2.4 GHz 频段，授权 Agent
选择有限参数；随后确认使用天线，并允许正常暂停另一项目采集。
这是新增的独立实验信号源授权，不把 TX 动作加入 P201/Planner，不恢复 P201
FPGA 加速或 NX 推理 offload，也不改变冻结 epoch-10/FP16/RF-v1 或生产 capability。

有限回放工具、P201 对照采集和清理完成；**RML2018A 空口链路尚未确认**。
三轮各发送 2,100,000 个 fc32 样本给 UHD，名义各 1 秒，子进程正常退出。
P201 共收到八个 65,535-sample ci16 窗口，零丢样/溢出/削顶，身份正确且恢复。
但已知片段相关性未区别于停发对照，不能只根据功率上升宣称接收到了该波形。
UHD 日志末尾均出现独立 `S` 标记，因此也不声称 TX 无异步错误。
当前待核对天线是否仍接历史确认端口，未继续加大发射或持续发送。

第三轮的 500 ms 只用于独立信号源同步诊断；没有改写冻结 RF-v1 profile。

累计输入 50,400,000 字节，但只保留一份 32,768 字节的临时循环片段，未产生长 IQ
发射文件。每轮打印有限计划、自由空间、SDR generation/stop 和精确目录。

最终一轮周期相关性：停发前 0.00143、发射中 0.00038、停发后 0.00124；

分析只用于工程辨识，不作为生产校准或拒识阈值。

## 工具与验证

- `prepare-b210-rml-train.py`：限定 train 成员哈希与四个选定样本，输出有界 tile/计划。
- `b210-finite-train-tx.py`：复用官方 `tx_samples_from_file`，FIFO ready 后仍等待
  stdin `GO`；无 `--repeat`，固定样本数，2 秒 feed watchdog，EOF/异常/信号回收
  子进程并删除 FIFO。远端 `timeout` 为 SSH 故障提供额外进程寿命上限。
- `validate-b210-p201-link.py`：拒绝活动 IIOD/非空闲 buffer，先取停发基线，
  只读监测 P201 调谐后触发 TX，记录 TX-start 与 RX-active，之后停发对照并独立
  核验恢复。完整 JSON 报告与 SigMF 限定在显式 feature 目录。
- `analyze-b210-p201-link.py`：仅访问本轮 tile/有界 IQ，计算周期相关与循环包络匹配。
- 4 项纯软件测试通过：精确字节/尾部哈希、GO 前 EOF 零发送、篡改拒绝，
  以及禁用检查的 Python `-O` 模式在硬件启动前拒绝；
  Python 语法及 diff 检查通过。实机后仅提取 `transmit()` 供测试、增加 UHD 标记
  记录和 `-O` 失败关闭检查，无波形/参数变化；审计分别保留实机版本与交付源码哈希。
