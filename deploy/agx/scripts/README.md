# AGX 脚本分类

[返回 AGX 入口](../README.md)。脚本按用途列于下方；Python 共享模块继续同目录放置，以保持导入关系。
验证入口可能访问硬件或调用模型，不因位于此目录而获得执行授权。实验脚本仅供历史复核，
执行前必须检查其数据、模型、有限计划和路径合同；它们不是默认部署入口。
